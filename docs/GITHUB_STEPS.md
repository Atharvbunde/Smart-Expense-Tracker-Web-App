# GitHub Upload Steps

```bash
git init
git add .
git commit -m "Initial commit - Smart Expense Tracker without MongoDB"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/Smart-Expense-Tracker-Web-App.git
git push -u origin main
```

Do not upload `.env` or `node_modules`.

Recommended repo description:
`A full-stack Smart Expense Tracker Web App built with React, Node.js, Express, JWT auth, JSON-file database, budget alerts and charts.`

Tags:
`react`, `nodejs`, `express`, `full-stack`, `expense-tracker`, `finance-app`, `jwt-auth`, `recharts`
