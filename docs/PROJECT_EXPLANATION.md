# Smart Expense Tracker Web App Explanation

A Smart Expense Tracker Web App helps users record income and expenses, classify spending, set budgets, and view reports through charts.

## Problem Solved
Many students and employees spend money without tracking it. This app shows where money goes and warns users when category budgets are crossed.

## Workflow
User login → add income/expense → category selected/auto-suggested → dashboard updates → chart analysis → budget alert.

## Why No MongoDB?
This version uses a simple JSON file database. It is easier for beginners because it does not require MongoDB installation, Atlas setup, or database connection errors.
